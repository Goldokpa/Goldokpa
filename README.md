# Gold Okpa

Founder and CTO of [IdentArk](https://identark.io) · Applied AI researcher · Birmingham, United Kingdom

I build security infrastructure for AI agents. IdentArk lets an agent take a real action, such as a payment, a pull request or a cloud change, without ever holding the credentials, and only within limits a human has approved.

## Building

- **[identark](https://github.com/identArk/identark)**: the Python SDK for IdentArk's AgentGateway. Agents get capabilities, not credentials; every high-risk action is approved, bound to the exact parameters executed, and audited.
- **[identark-js](https://github.com/identArk/identark-js)**: the TypeScript SDK.
- **[identark-cli](https://github.com/identArk/identark-cli)**: command-line client for credential references, approvals and managed access.
- **[n8n-nodes-identark](https://github.com/identArk/n8n-nodes-identark)**: n8n community node, so an n8n instance holds zero API keys.
